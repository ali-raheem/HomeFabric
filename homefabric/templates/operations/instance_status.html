Backup and recovery

Backups are created from the command line so they can be automated. Archives contain password hashes and all household data: store them encrypted (for example with age, gpg or 7-Zip AES-256) and off the host.

python manage.py backup --output /path/to/backups/ python manage.py verify_backup /path/to/archive.zip python manage.py restore /path/to/archive.zip --dry-run

Restoring replaces the whole instance. Stop the web server and scheduler first, then run restore … --confirm. Notifications stay paused afterwards until you resume them here. See the operator guide for full disaster-recovery steps.
