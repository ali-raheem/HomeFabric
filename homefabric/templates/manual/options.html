Making a PDF

  1. Choose View and print, then Print or save as PDF. You can also open a downloaded file in any browser and use Print.
  2. Select “Save as PDF” as the printer and turn on Background graphics so the colours print.

The single HTML file works offline and includes small photos, but not the document files. The ZIP{% if not perm.export %}, which only household owners can download,{% endif %} contains the manual and every document it mentions, linked so that they open from the manual.
